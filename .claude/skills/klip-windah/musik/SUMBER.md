# Musik latar (backsound)

Dibuat otomatis oleh `klip-windah sinkron-sfx` dari folder Drive pengguna (lihat `sfx/SUMBER.md`).
File musik tidak di-commit.

Rencana: `"musik": true` (backsound terbaru di musik/) atau `{"file": "musik/<nama>_loop.wav", "volume_db": -15,
"duck_ratio": 6}`. Dipasang di bawah kartu hook + klip (endcard tidak disentuh), ducking sidechain dari suara klip.
Cek sambungan loop bila perlu: energi >16 kHz di sambungan harus setara tengah bar (klik = lonjakan).
Hak cipta: audio TikTok bisa kena klaim; ingatkan pengguna (alternatif: pasang sound di app TikTok saat upload).
